# Руководство пользователя (ЭнергоПульс)

Этот документ описывает, как пользоваться системой в локальном режиме: запустить, загрузить файлы, проверить результат и при необходимости очистить данные.

---

## 1. Запуск системы

### Backend API

Из корня проекта:

```bash
python3 -m venv .venv
.venv/bin/pip install -e apps/api
.venv/bin/uvicorn app.main:app --app-dir apps/api --reload --host 127.0.0.1 --port 8000
```

Проверка:

```bash
curl http://127.0.0.1:8000/healthz
```

Ожидаемый ответ:

```json
{"status":"ok"}
```

### Frontend

В отдельном терминале, из корня проекта:

```bash
npm install
npm run dev
```

Открой в браузере:

- `http://localhost:5173`

---

## 2. Загрузка файлов

1. Открой раздел **«Качество данных»**.
2. Нажми **«Загрузить файлы»**.
3. Выбери один или несколько файлов формата:
   - `.xlsx`
   - `.xls`
   - `.csv`

После успешной загрузки:

- появится toast об успехе;
- в таблице **«Загруженные файлы»** появятся новые записи;
- откроется/обновится аналитический экран энергобаланса.

---

## 3. Где смотреть результат

### На странице «Качество данных»

- таблица загруженных файлов;
- статус обработки;
- количество строк;
- замечания (если есть).

### На странице «Энергобаланс»

- агрегированная бизнес-аналитика по загруженным данным;
- графики и KPI.

---

## 4. Очистка всех данных

В системе есть кнопка **«Очистить всё»** в левом sidebar (внизу).

Что она удаляет:

- все import batches;
- все import files;
- все staging rows;
- все validation issues;
- все raw-файлы в `data/raw-imports`.

После нажатия:

1. система попросит подтверждение;
2. выполнит полный сброс;
3. перезагрузит список импортов.

> ⚠️ Действие необратимое.

---

## 5. Если «ничего не происходит» при загрузке

Проверь по шагам:

1. Запущен ли backend (`http://127.0.0.1:8000/healthz` отвечает `ok`).
2. Открыт ли frontend с актуальным кодом (`http://localhost:5173`).
3. Есть ли сообщение об ошибке (красный toast с `HTTP ...: ...`).
4. Обнови страницу жёстко: `Cmd + Shift + R`.

Если API недоступен, интерфейс покажет ошибку подключения.
Если сервер вернул ошибку валидации/обработки, интерфейс покажет текст `detail` из API-ответа.

---

## 6. Полезные API для ручной проверки

```bash
# список загрузок
curl http://127.0.0.1:8000/api/v1/imports

# превью конкретного импорта
curl http://127.0.0.1:8000/api/v1/imports/1/preview

# полный сброс данных
curl -X POST http://127.0.0.1:8000/api/v1/admin/reset
```
