# ЭнергоПульс — business value plan

Дата: 2026-07-27

## 1. Для кого экран

Основной пользователь — главный энергетик и операционный руководитель. Экран должен помогать принять пять решений:

1. Растёт или снижается общее энергопотребление.
2. Какая часть относится к ТОО «Казах Ойл Актобе», а какая — к сторонним организациям.
3. Какие направления и контрагенты формируют наибольшую нагрузку.
4. В какие дни возникали пики и есть ли пропуски или отрицательные интервалы.
5. Сходятся ли ежедневные сводки с месячным техническим балансом.

## 2. Первая версия дэшборда

### KPI

- общий вход за последний доступный месяц, кВт·ч;
- собственное потребление КОА, кВт·ч и доля от общего входа;
- потребление сторонних организаций, кВт·ч и доля;
- изменение общего входа к предыдущему месяцу;
- число дней ежедневного покрытия;
- число отрицательных или неполных интервалов.

### Визуализации

1. **Месячная динамика** — stacked bars `КОА + сторонние организации` за январь–март.
2. **Ежедневная нагрузка** — линия по контролируемым вводам за 90 дней с обозначением пикового дня.
3. **Распределение по линиям 35 кВ** — вклад линий Север, Южная, Кожасай и УКПГ за последний месяц.
4. **Сторонние организации** — крупнейшие конечные потребители и группировка по площадкам.
5. **Сверка источников** — monthly technical balance против суммы daily summary на одинаковой контрольной границе.

## 3. Правила расчёта

- расход физического счётчика пересчитывается независимо:
  `(следующее показание − текущее показание) × коэффициент`;
- формулы и cached values Excel не считаются первичным источником;
- общий месячный вход берётся только из финального блока вводов техбаланса;
- собственное потребление: `общий вход − сторонние организации`;
- сторонние организации агрегируются из индивидуальных строк листа, без строк `Итого`;
- дневная динамика строится на общей для daily/monthly контрольной границе:
  два ввода 110 кВ и ввод 35 кВ «Южный Жанажол»;
- отрицательные интервалы и строки с неполными показаниями не исправляются молча.

## 4. Ограничения

- линии разных уровней напряжения нельзя суммировать как независимых потребителей: это создаёт двойной счёт;
- сумма daily на контрольной границе не равна полному месячному входу, пока в daily-файлах отсутствуют все дополнительные вводы;
- стоимость по тарифу не публикуется, пока заказчик не утвердил billable boundary и правило округления;
- показатели экрана являются операционной аналитикой, а не утверждённым бухгалтерским расчётом.

## 5. Критерии готовности

- январь–март отображаются одной временной шкалой;
- итог КОА плюс сторонние организации равен общему месячному входу;
- daily/monthly сверяются только на одинаковой контрольной границе;
- крупнейшие сторонние потребители рассчитаны по конечным строкам, без subtotal;
- экран явно показывает период, единицу измерения и качество покрытия;
- при отсутствии одного из наборов соответствующая визуализация показывает понятное пустое состояние.
